# RainRang — Everyday Art

A first runnable browser prototype for the DJXHack concept.

## Run locally
1. Download and extract `rainrang-prototype.zip`.
2. Open the `rainrang` folder in VS Code.
3. Open `index.html` in your browser. You can also use the VS Code Live Server extension.

No build tools, backend, API keys, or installation are required.

## Included in this prototype
- Responsive landing page and interaction explainer
- Interactive Canvas with click/tap-generated rangoli marks
- Pointer movement trails
- Six colour choices and three creative modes
- Simulated rain mode
- Undo, reset, light/dark theme toggle
- Download artwork as PNG

## Current limitations
- Sound, camera/hand tracking, object recognition, shadows, and multi-user sharing are concept/future features, not implemented in this MVP.
- The Google Fonts import is optional; if offline, the page falls back to system fonts.
